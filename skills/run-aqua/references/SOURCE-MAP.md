# AQUA source map for maintainers

The distributable skill is self-contained. Its methodology was derived from the accepted canon at build time. When revising it, inspect these primary local sources if available:

- `outputs/aqua-canon/Planning/AQUA-AGENT-PLUGIN-BUILD-GUIDE.md` — current agent plugin build direction.
- `outputs/aqua-canon/A-APPLICATIONS-FINAL.md` — application, program, source and terms ownership.
- `outputs/aqua-canon/Domains/FOUR-FUNNELS.md` — Tech, Jobs, College, Grants Funding.
- `outputs/aqua-canon/QU/CONSOLIDATION.md` — current family, variant and auxiliary interpretation.
- `outputs/aqua-canon/QU/WORKFLOW.md` and `INTAKE-RULE.md` — A captures; QU organizes.
- `outputs/aqua-canon/QU/ANSWER-COVERAGE.md` — partial answer reuse and context.
- `outputs/aqua-canon/QU/Question-Index.csv`, `Question-Directory.csv`, `Question-Variants.csv` — examples, not packaged user data.
- `outputs/aqua-canon/Planning/A-QU-Harvest-Plan.csv` — detailed historical transitions.

The existing website repository is `https://github.com/SunrisesIllNeverSee/application-hub`. Its older answer and MCP code is historical implementation material, not an automatic replacement for this skill. Do not ship the private originals from `outputs/aqua-canon/Entities/.../Documents/Originals/` or the old review workbook/HTML as plugin data. The personal plugin does not require access to the source package at runtime.
